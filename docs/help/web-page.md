# Web page

The line under the command line is these charts' link on the program's web page, [ratesplot.streamlit.app](https://ratesplot.streamlit.app). Opened in a browser, it draws the same charts, for anyone and with nothing to install: the chart's command line is in the link, after `?chart=`. It follows every change of the controls, as the page's own address does.

## Using it

In the window, Copy beside the link puts it on the clipboard, and Go opens it in your browser. On the web page, the copy button at the right of its box does the same, and Go beside it opens the link in a new tab: a copy of the charts that goes on by itself, the tab it came from left as it is. A copied link can be bookmarked, or sent to someone to show them the same charts.

## What it draws

The same charts, drawn from the sources as they stand when the link is opened. With End left blank it draws up to that day, so the same link opened later shows the latest data; with a date typed, the same span ([Start and End](?help=dates)). On a narrow screen the page draws a smaller chart with larger text, but the link is the controls', so it draws the full-size chart on a wider one ([Size and layout](?help=layout)).

The default charts' link ends `?chart=` with nothing after it. The page's address with no `?chart=` at all opens on the settings your browser remembers from your last visit, while "Remember my settings" was ticked, and otherwise on the default charts.

The data exported from the page end their subtitle with the version that wrote them; `--no-ver` in the link leaves it out ([Command line](?help=command-line)).

The same charts with the program on your own computer: [Command line](?help=command-line).
